# Acessibilidade

O blog da URE Marília se compromete a oferecer um site acessível a todos os usuários, independentemente de habilidades ou condições.

## Recursos de acessibilidade

- **Navegação por teclado:** todo o site pode ser navegado usando apenas a tecla `Tab`.
- **Pular para o conteúdo:** link no topo da página para pular diretamente para o conteúdo principal.
- **Foco visível:** elementos interativos destacam claramente quando recebem foco.
- **Contraste:** cores com contraste adequado para leitura.
- **Textos alternativos:** imagens carregadas possuem descrição alternativa.
- **Redução de movimento:** animações respeitam a preferência `prefers-reduced-motion` do navegador.
- **Tamanho de alvo:** botões e links têm pelo menos 44 px de área clicável.

## Impressão

O site está otimizado para impressão. Materiais didáticos podem ser baixados e impressos sem perda de qualidade.

## Feedback
